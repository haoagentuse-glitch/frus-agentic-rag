<!-- session:c743e017-428f-4f92-8fa9-14746007237e turn:0709bfe9-f5a7-4512-ad41-94b5d4507177 transcript:/home/haoche_nitro_v15/.claude/projects/-home-haoche-nitro-v15-FRUS-agenticRAG/c743e017-428f-4f92-8fa9-14746007237e.jsonl -->
- User asked Claude Code to explain three evaluation metrics in detail: `attribution_min_score`, `focus`, and `citation_precision`.
- Claude Code measured `attribution_min_score` across 29 claims and 6 questions, finding that the current threshold of −6.0 filters nothing (100% retention rate), revealing the mechanism is inert.
- Claude Code identified the threshold was incorrectly calibrated by analogy to a different metric rather than measured for claim-passage pairs, which have a median cross-encoder score of 4.473 compared to the threshold of −6.0.
- Claude Code decided not to raise the threshold after discovering that non-gold document passages scored higher (median 7.148) than gold passages (median 4.145), revealing that `attribution_min_score` measures source identification rather than correctness and cannot filter unsupported claims.
- Claude Code explained `focus` as a sentence-level filtering mechanism that ranks sentences by cross-encoder score, selects the top 4 per passage, and expands each with ±1 context sentences, isolating this filtering to only the `text_focus` field while preserving original text for retrieval and validation.
- Claude Code reported that `focus` has been measured for text retention (63-74%) and computational cost (2-4 seconds on GPU), but effectiveness for correctness has never been validated.
- Claude Code explained `citation_precision` as the proportion of referenced documents that appear in gold answer sets, and identified two key limitations: post-hoc methods with `attribution_top_k = 3` mechanically increase cited documents compared to previous approaches, making cross-method comparisons unfair; and the metric penalizes citing relevant non-gold documents rather than detecting actual citation errors.
- Claude Code concluded that all three metrics require careful interpretation: `attribution_min_score` is validated as inert, `focus` effectiveness is unmeasured, and `citation_precision` cannot be fairly compared across different attribution methods.
